# 扫描样板测量

源: https://www.bjxch.gov.cn/file/20220601/1654063400276033723.pdf

用 PyMuPDF 以144dpi渲染第一页, 按颜色像素包围框测量. 1pt = 1/72英寸. 扫描图本身有裁切和旋转误差, 测量精度约0.5pt. 测量的是扫描墨迹, 不等同于原文档的排版框.

| 元素 | 左边/上边/右边/下边 (pt) |
| --- | --- |
| 页面 | 0 / 0 / 595 / 841 |
| 红头墨迹 | 101 / 216 / 487 / 263.5 |
| 红线墨迹 | 84.5 / 343.5 / 507.5 / 347 |
| 发文字号墨迹 | 221.5 / 318.5 / 365.5 / 332 |
| 标题第一行墨迹 | 158.5 / 432 / 429.5 / 452 |
| 标题第二行墨迹 | 120.5 / 459.5 / 474.5 / 480 |

定制页与扫描件的文字长度不同: 红头改为8字, 编号更长, 正文标题改为单行. 保持居中轴和字号比例, 不强制将不同文字拉伸到相同横向宽度.

保留定制项: 六角括号的课程编号, 半角标点, 左对齐正文, LaTeX公式. 本地存在仿宋, 缺少小标宋. 版头纵向1.4倍拉伸为近似措施, 不能代替字体匹配.

## 本地打印校准结果

Chrome153, A4, CSS页尺寸, 100%缩放. 固定正文宽度并限制长公式容器后, 正文实际为15.9975pt, 标题为21.9975pt, 消除了浏览器整页缩小. 本地打印正文标题墨迹为y432..452pt, 与样板第一行一致; 红线横向为x84.5..507.5pt, 与样板一致. 编号墨迹已调整到y318.5pt; 红头墨迹上缘调整到y216pt. 字体差异仍未解决, 不宣称像素完全一致.
